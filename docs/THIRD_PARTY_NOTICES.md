# Notices de composants tiers

## `mtg-card` — FeSens

- Dépôt : https://github.com/FeSens/mtg-card
- Paquet : https://www.npmjs.com/package/mtg-card
- Version intégrée : 0.1.1
- Auteur déclaré dans le manifeste npm : Felipe Bonetto
- Licence déclarée dans le `package.json` amont et dans son README : MIT.
- Usage dans ce projet : dépendance npm, sans copie manuelle du répertoire d'assets.

Le README amont indique que les SVG de cadres et la mise en page s'appuient sur le fichier communautaire Figma **MTG Card Designer** de **@ux_andrew** : https://www.figma.com/community/file/773439497184575668. Cette provenance est conservée ici à titre d'attribution. La licence MIT déclarée pour le paquet ne remplace pas la vérification des conditions attachées au fichier Figma et à ses ressources d'origine.

**Point de contrôle avant distribution publique :** le dépôt GitHub amont consulté ne contient pas de fichier `LICENSE` séparé, bien que le manifeste npm et le README déclarent MIT. Il faut obtenir/confirmer le texte de licence et les droits de redistribution des ressources Figma auprès des auteurs avant de publier des binaires ou de redistribuer les assets hors du paquet npm.
