# Asset Library — sélection normalisée

Ce répertoire est réservé aux ressources sélectionnées pour l'application après validation.

## Conditions d'entrée

Un fichier ne peut être copié ici que lorsque :
1. son identité et son usage ont été examinés visuellement ;
2. son format, ses dimensions et sa transparence ont été contrôlés ;
3. sa provenance est documentée ;
4. sa licence et les droits d'incorporation/redistribution sont vérifiés ;
5. son nom, son identifiant et ses layouts compatibles sont enregistrés dans le manifeste ;
6. un test de rendu pertinent passe.

## Convention cible

`<category>/<family>/<asset-id>--<descriptive-name>.<ext>`

Catégories : `Frames/`, `Components/`, `Symbols/`, `Tokens/`, `Fonts/`.

Ne pas copier les collections sources en bloc. Ne pas créer de fichiers de production à partir d'une ressource dont la licence est `unknown` ou `pending-review`.

## État initial

Aucun fichier graphique n'est encore approuvé pour cette bibliothèque. Les inventaires sous `Assets/METADATA/inventory-*.json` sont des inventaires de sources, pas des listes d'assets normalisés.
